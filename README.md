# Activities

1. **Transfer learning and fine-tuning:** A transfer learning and fine-tuning process was executed on the MobileNetV2 model to classify types of skin lesions using the MNIST: HAM10000 dataset.

2. **SLAM and YOLO:** SLAM was used to map an image via point clouds, and YOLO was used to identify moving objects and eliminate points that were mapped onto those objects. The dataset used was the KITTI dataset for 2D object tracking.

3. **3D object representation and classification:** 3D objects in point cloud format were utilized, and their classification process was tested in mesh and mash formats. The dataset used was ModelNet40. 

4. **Context enrichment:** A project was carried out using YOLO to classify objects in a scene, BLIP to provide more details about what is happening in the scene, and CLIP to perform a probability analysis of the scene's events. Finally, all these results were combined into a prompt for the Qwen LLM to generate a response regarding an action to be taken in the context of the image.

## Final Project

A project was developed to extract features from the coastline. As a result, an algorithm was created that generates images highlighting certain coastline features through the generation of several different types of image models. It also performs the segmentation of the sea from the land and automates the process of obtaining new coordinates to acquire new images.

4. Enriquecimento de contexto: foi feito um trabalho usando YOLO para classificar objetos em uma cena, blip para dar mais detalhe do que está acontecendo na cena, clip para fazer uma analise de probabilidade do que está acontecendo na cena e por fim, a únião de todos esses resultados em um propmt para a LLM Qwen para gerar uma resposta sobre uma ação para ser tomado no contexto da imagem.
